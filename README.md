# APOLO 5 — Landing page

Equipo 5 · Grupo 4 · Integrante del proyecto Rocket Tec Sinaloa 2026.

Landing page estática lista para GitHub Pages.

## Publicar en GitHub Pages

1. Sube el contenido de esta carpeta a un repositorio.
2. En **Settings → Pages**, selecciona **Deploy from a branch**.
3. Elige la rama principal y la carpeta `/ (root)`.
4. Guarda y abre la URL que te entregue GitHub.

No necesita Node, npm ni compilación. El contador está configurado para el **miércoles 2 de diciembre de 2026 a las 7:00 a. m. (hora de Culiacán, UTC−7)**.

La página incluye un botón para activar el soundtrack local en formato MP3. El visitante debe hacer clic para iniciarlo porque los navegadores bloquean el autoplay con sonido.
